# 02. 스토리 바이블 — 현행 시나리오 통합 정리

> HELP.TXT(설정) + PROLOG.CAP/PROLOG2.CAP(대본) + TALK.TXT(게임 대사) + 소스 주석을
> 교차 검증하여 하나로 통합한 **현행 시나리오 기준 문서**. 개편 작업의 원전.

---

## 1. 로그라인

> 폭우 내리는 아침, 화공과 조교가 버린 실험 찌꺼기에 감염된 모교수가 괴물로 변해
> 공대 건물을 봉쇄한다. 갇힌 전산학과 학생 **부싯돌**(주인공)은 괴물이 된 교수를 되돌리고
> 건물을 정상화하기 위해 5개 층을 헤집는다.

- **장르 톤**: 학교 배경 호러 코미디 (원문에 반복 등장하는 개그 코드: "3류 공포물", "농구", 짜장면)
- **제작 의도** (HELP.TXT 명시): "교수님들이 자기의 욕망보다 양심으로 생활했으면" —
  학생 시점의 야유 섞인 풍자가 주제

## 2. 세계관 / 무대

### 2.1 공대 건물 구조 (HELP.TXT 기준)

| 층 | 학과/시설 | 맵 파일 | 에피소드 대본 |
|---|---|---|---|
| 지하 | 휴게실·등전(?), 식당 | F0.MAP | 없음 |
| 1층 | 식품공학과, 현관, 교무과, 창고, 비밀통로 | F1.MAP (**시작 지점**) | ✅ PROLOG.CAP |
| 2층 | 전자계산학과, 실습실, HP실 | F2.MAP | ✅ PROLOG2.CAP |
| 3층 | **화학공학과** (사건의 핵심) | F3.MAP | ❌ (게임 내 대사만 존재) |
| 4층 | 전자공학과 | F4.MAP | ❌ |
| 5층 | **중앙통제실** (결말) | F5.MAP | ❌ |

※ 주의: 게임 내부 층 인덱스 `f`(0~5)와 건물 층 번호는 일치하지 않음 (F1=1층 시작 확인).
PROLOG2.CAP만 "중앙통제실=3층"으로 잘못 적음 — HELP/TALK의 **5층이 정설**.

### 2.2 사건의 경위 (발단)

1. 오전 8:30, 폭우. X교수(모교수) 출근.
2. 3층 화공과에서 며칠간의 실험이 실패로 끝남.
3. 조교가 찌꺼기를 분리수거 대신 **3층 화장실 바닥에 방치**.
4. 액체가 2층 화장실 천장으로 누수 → 손 씻던 모교수에게 감염.
5. 양심·자제력 붕괴, 본능 폭주 → 괴물 변이.
6. 모교수는 5층 중앙통제실을 장악해 **모든 자동문 봉쇄**,
   화학약품 조합으로 **인조인간 괴물**을 복도마다 배치.
7. 목격한 주인공은 실습실로 피신 — 여기서 게임 시작.

### 2.3 해결의 사슬 (메인 퀘스트 골격)

```
[1] 탈출 시도 실패 (현관 이중 봉쇄)
      ↓ 수위의 단서 + 여자의 의뢰
[2] 1층: DWORM 격퇴 → 교무과 폭탄(소포) 수령 → 우편물 선배 괴물 사건
      ↓ 라이터+도화선(휘발유) 확보, 재영이/삼룡이 괴물 이벤트(동료의 희생=EXP)
[3] 폭파로 2층 문 개방
[4] 2층: HP실(개발팀 크레딧룸) → 친구의 컴퓨터 폭발 → 신기술 습득
      ↓ 완종이 괴물(약점: 만화 포스터) 격파 → 3층 개방
[5] 3층: 화공과 교수 = 해독제 제작자 발견
      재료 3종 필요: {드래그, 앨린, 팰린}
        드래그 = 식초 + 요소 + 건전지100V
        앨린   = 진공관 + 건전지200V
        팰린   = 알콜 + 건전지10000V
      ↓ 황별팔 박사·실습조교·정보원 NPC들의 단서로 재료 수집  ← [미완성: "2부"]
[6] 해독제 투여 → 모교수 인간 복귀
[7] 그러나 중앙컴퓨터가 AI화하여 자율 폭주  ← [구현 안 됨]
[8] 인터넷/책(아이템 '책') 조사 → 바이러스 디스크(아이템 '디스크 3.5인치') 제작
[9] 5층 통제실에 디스크 삽입 → 건물 정상화 → 엔딩   ← [구현 안 됨]
```

## 4. 챕터 구조 & 분기

### 4.1 1층 에피소드 (PROLOG.CAP)

```
오프닝 자막 → 현관 봉쇄 확인 → 여자1 의뢰 → DWORM 전투
├─ 승리: 남자1과 대화, 괴물 3마리 증언
└─ 패배: 주인공 KO → 남자1이 처리, 부활 개그
→ 교무과 방문(점심시간 클로즈 개그) → ROCKER(가수) 스루개그
→ 교무과 오픈 → 우편물 보관실 선배 괴물 전투
├─ 승리: 여자2가 제지 ("더 때리지 마세요") → 전화 불통 확인
└─ 패배: 여자2가 막다가 피격 → 선배 스스로 정신 회복 (여자2를 지키려는 본능)
→ 소포(폭탄) 수령 → 수위와 대화 → 비밀통로 → 창고
→ 라이터+실 약탈 시도 → 괴물이 삼킴 → 전투 → 라이터만 회수
→ 재영이 괴물: 저항 없음, 자발적으로 힘(EXP) 증여 후 쓰러짐 ★감동 포인트
→ 삼룡이 괴물: 아르바이트 회상 후 전투, 휘발유 획득
→ 폭탄+휘발유+라이터 조합 → 점화 → 괴물 5마리 급습 격파 → 대폭발 → 1층 종료
```

### 4.2 2층 에피소드 (PROLOG2.CAP)

```
2층 진입 → 농구공 발견(복선) → HP실: 개발팀 크레딧룸 (메타 개그)
→ 조교실(승/정 2인 대사) → 좌우 사람(끈질기면 화공과 교수 정보)
→ 3층 계단 봉쇄 확인 → 농구 학생과 대화
   · 괴물 인지 불가 개그 → 괴물 습격 → 전투 후 인지
   · 화장실 연기 단서 → 화장실 조사(남/녀 화장실 개그, 용 쓰는 여학생 목격)
→ 실습실: 친구와 재회(게임 자랑) → 정선이 괴물 습격
   · 액체 회피 밀치 → 컴퓨터 누전 폭발 → 주인공 피해 + 정선이 기절
→ 친구: "내 게임의 기술이네!" → 신기술 '연속펀치' 습득 + EXP ★
→ 완종이 괴물: "싸우고 싶다"
├─ 승리: 통과
└─ 패배: 도주 → 만화 포스터 획득 → 사용 시 완종이 공/방 0 → 재도전
→ 3층 문 개방 → 2층 종료
```

### 4.3 3층 이후 (TALK.TXT 범위 = 구현된 것만)

- 화공과 교수 체인: 대면(#0-7) → 조교 추궁(#22-37) → 해독제 의뢰(#8-21) → 재료 정보(#146-167: 황별팔/실습조교/정보원들이 각각 드래그·앨린·팰린 힌트 제공) → **재료 수집 및 투여는 미구현**
- 권교수 심부름 3연속(단무지/식초/껌 → 돈+HP)
- 홍춘발↔남앵골 정보 체인(v_Hong/v_Nam 플래그)
- 나머지: 퀴즈맨, 상점, 홍보부장, 서시 이벤트, NOTHING류 잡담
