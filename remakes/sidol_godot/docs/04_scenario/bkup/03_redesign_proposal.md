# 03. 시나리오 개편 방향 (Redesign Proposal)

> ⚠️ **SUPERSEDED (2026-08-24)**: 본 개편안은 **[../03_remake_scenario_master.md](../03_remake_scenario_master.md)**
> (통합 리메이크 마스터 시나리오)로 확정되었다. §6 다중 엔딩 제안은 마스터의
> "단일 메인 엔딩 + 후일담 카드 3종"으로 덮어써졌으며, CH4~CH6 골격도 마스터가 권위.
> 본 문서는 의사결정 이력 참조용으로만 유지한다.

> 원칙: **원작의 목소리는 유지, 뼈대는 완성**. HELP.TXT가 그린 결말(바이러스 디스크)까지
> 실제 플레이 가능한 스토리로 완성하되, 1995년의 만담 톤과 패러디 정신은 보존한다.

## 1. 개편의 3축

| 축 | 현황 | 개편 |
|---|---|---|
| **완결성** | 대본 1~2층만 존재, 게임은 화공과 의뢰까지 | 전 6개층 에피소드 + "2부"(약품) + 진엔딩 집필 |
| **구조화** | 하드코딩 switch + 번호 리터럴 | DialogueTable 데이터 주도, 플래그 조건 분기, 선택지 도입 |
| **밀도** | 오프닝 대본이 6줄로 축약됨 | CutscenePlayer로 PROLOG 대본 충실히 무대화(요약본+풀버전 병행) |

## 2. 신규 챕터 구조 (개편안)

```
프롤로그   : 모교수 변이 몽타주 (PROLOG.CAP 도입부 → 컷신)
CH1 1층    : 탈출 실패, DWORM, 폭탄 소포, 재영이·삼룡이 이벤트, 폭파 개방   [원작 대본 있음]
CH2 2층    : HP실 크레딧룸, 정선이 사건, 기술 습득, 완종이(만화 포스터)      [원작 대본 있음]
CH3 3층 ★  : 사건의 진상(조교 추궁), 해독제 의뢰, 재료 단서 수집            [TALK.TXT 범위]
CH4 4층    : [신규] 전자공학과 — 앨린(진공관)·고전압 건전지 확보
             · 권교수 심부름 체인을 여기에 통합(단무지→식초→껌)
             · 나박사/김교수 서브 스토리 확장
CH5 5층    : [신규] 중앙통제실 접근 — 보스: 강화 괴물들 + 모교수 전투
             · 해독제 투여 → 모교수 인간 복귀 → "컴퓨터가 멋대로…" 반전
CH6 지하/종반 : [신규] AI 컴퓨터 퍼즐 던전 — 바이러스 프로그램 작성
             · '책' 아이템 + 인터넷실 자료 조합 → 디스크 제작 미니게임
             · 디스크 삽입 퍼즐(보안 절차 개그) → 엔딩
에필로그   : 건물 정상화, 크레딧(HIP방 멤버 연출 연계)
```

- CH4~CH6는 HELP.TXT 줄거리를 그대로 골격으로 사용(이미 결말까지 설정 완료).
- 각 층 클리어 보상으로 **신기술 습득**(2층 '연속펀치' 패턴 확장) — 성장 곡선과 연동.

## 3. 톤 코드 (집필 시 필수 준수)

1. **"3류 공포물" 자인식 개그는 시그니처** — 긴장 장면 직후 반드시 브레이커 배치.
2. 교수 패러디는 악의가 아닌 **애정 어린 풍자**로 유지 (HELP.TXT의 제작 의도 계승).
3. 감정 포인트는 희생 없이: 괴물 동료(재영이 등)는 죽지 않고 **힘을 남기고 기절**하는
   원작 규칙 유지 — "해독제로 모두 되돌릴 수 있다"는 희망 구조.
4. 메타 유머(퀴즈맨, HP실 크레딧룸)는 리메이크 시점 정보로 갱신 가능하되
   원문 보존판을 옵션으로 병기(레트로 모드).

## 4. 대사 시스템 개편안

### 4.1 참조 체계

```jsonc
// dialogue_v2.json
{
  "@t0":    "음!... ",                       // 원문 보존 (변경 금지 영역)
  "@c300":  { "text": "신규 대사…", "scene": "CH5", "speaker": "mokyo" },  // 신규
  "@v2000": "…원문 복구 불가 행…"            // 복구 마커
}
```

- `@t*` = 원작 TALK.TXT 인덱스(절대 재배열 금지), `@c*` = 신규, `@v*` = 복원 필요.
- 신구 혼용 가능 → 부분 개편 안전.

### 4.2 분기 고도화

- 원작: NPC당 플래그 if-else (v_Howa 0/1/2).
- 개편: **선택지 추가** — 예) 조교 추궁 장면에서 "용서한다/때린다" → 플래그 분기 후
  후반 대사 마이크로 변화. 전투 회피/설득 옵션 검토(CH3 조교 설득 루트).

## 5. 퀘스트 재구성표

| ID | 퀘스트 | 상태(원작) | 개편 |
|---|---|---|---|
| Q_MAIN | 드래그·앨린·팰린 수집→해독제 | 의뢰까지만 | CH4~5로 완성. 재료별 획득 미니 이벤트 부여 |
| Q_QUAN | 권교수 심부름 3연속 | 구현됨 | CH4 이관, 최종 보상을 고전압 건전지로 변경 |
| Q_HOWA | 화공과 체인 | 구현됨 | 유지+선택지 추가 |
| Q_KEY | 열쇠/실습실 | 부분 | CH2~3 관문으로 명확화 |
| Q_VIRUS | 바이러스 디스크 | **설정만** | CH6 신설(책+자료→디스크) |
| Q_QUIZ/Q_SHOP/Q_HP | 퀴즈/상점/크레딧룸 | 구현됨 | 유지, 퀴즈 문항 현대화 옵션 |

## 6. 엔딩 설계 (HELP.TXT 기반 확정)

```
해피: 디스크 투입 → AI 붕괴 → 전원 해독 → 에필로그(학회 풍경, 농구공 회수 회수 개그)
노멀: 해독제 없이 통제실 강제 폭파 루트 → 일부 NPC 미복귀 서브 엔딩 (선택지 결과)
숨겨진: 퀴즈 전문 + 권교수 심부름 완수 시 진실 노트 해금 (모교수의 사전 연구 일지)
```

- 다중 엔딩은 원작에 없으나 HELP.TXT의 "모든 물음의 해답은 건물 안에 있다"를
  수집 요소로 승화시키는 최소 범위 제안. 스코프 과열 시 해피 엔딩 단일로 축소(G-SCOPE).
