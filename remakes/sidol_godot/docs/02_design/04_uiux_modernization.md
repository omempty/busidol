# 04. UI/UX 현대화 + 아트 스케일업 설계

> "충실한 이식"이 아니라 **현대 RPG 트렌드를 맞춘 리메이크**. 원작의 감(그리드 이동,
> 만담 톤, 패러디 유머)은 보존하되, 불편함·미구현·구시대 UI는 전면 개선.

## 0. 원칙 — 어디까지 원작을 따르는가 (2026-08-29 확정)

**층을 나눠서 정한다.** 하나의 잣대로 "충실도"를 재면 매번 같은 논쟁이 되풀이된다.

| 층 | 기준 | 예 |
|---|---|---|
| 큰 문맥 | **원작을 따른다.** 바꾸려면 마스터 시나리오를 먼저 고친다 | 줄거리와 층 구성, 맵 지형, 아이템·적 수치의 근거, 이벤트가 일어나는 자리 |
| 세세한 연출 | **현대 게임 트렌드를 적극 도입한다. 원작에 없어도 넣는다** | 상자 개봉 애니메이션·효과음, 문 통과 연출, 피격 히트스톱, 화면 전환, 커서·프롬프트 피드백 |

그러므로 조사 결과가 "원작에는 없었다"로 나와도 **그것은 넣지 않을 이유가 아니다.**
원작 대조는 ① 있으면 재현의 근거(원작이 이미 답을 냈다) ② 없으면 설계 자유도가 크다는
표시, 둘 중 하나로만 쓴다. 반대로 큰 문맥에서 원작과 갈리면 그건 결함으로 다룬다.

판단이 갈리는 자리(원작 소스에 흔적은 있으나 주석 처리된 것 등)는 연출 층이면
**켜는 쪽**을 기본값으로 한다 — 예: `GOODITEM.C`의 `door.voc` 문 효과음.

## 1. UI 전면 재설계

### 1.1 HUD (원작: 우측 8자리 숫자 스프라이트 → 현대형)

```
┌───────────────────────────────────────────────┐
│                                               │
│              필드 뷰포트                        │   ┌────────────┐
│           (Camera2D, 부드러운 추적)             │   │ LV 12      │
│                                               │   │ HP ▓▓▓▓░░ │
│                                               │   │ EXP ▓▓░░░  │
│                                               │   │ ⚡ AP  🛡 DP│
│                                               │   │ ¤ 5,000    │
│                                               │   └────────────┘
└───────────────────────────────────────────────┘   [아이템 슬롯 미니 4칸]
```

- 숫자 스프라이트(NUM[].SPR) → 동적 Label+비트맵폰트. 자릿수 제한(8자리) 제거.
- HP바는 즉시값이 아니라 **트윈 감소 + 낮을 때 펄스 경고**.

### 1.2 대화창 (원작 Talk_Window 개선)

| 항목 | 원작 | 개선 |
|---|---|---|
| 출력 | 한 글자씩(HANGUL_DELAY) + 키 대기 | 타이핑 효과 + **스킵(누르면 즉시 완성)** + 오토프레이 옵션 |
| 페이징 | 3줄 고정, 타임아웃 진행 | 흐름 기반 + **대화 로그(히스토리) 열람** |
| 화자 | 이름 텍스트만 | **초상화(FACE*.PCX 활용) + 화자색 하이라이트** |
| 선택지 | 없음(퀴즈만 별도 구현) | 공통 choice 컴포넌트(게임패드 지원) |

### 1.3 메뉴/인벤토리

- 원작: 가로 아이콘 4개(도움말/아이템/io/기타), 인벤토리는 가로 스크롤 리스트.
- 개선(2026-08-30 전부 구현):
  - **탭형 메뉴** (아이템 / 장비 / 상태 / 시스템) — `InventoryPanel`, I키. Q/E로 탭 이동.
  - **마우스+패드+키보드 삼중 내비** — 패드는 `input_bootstrap`의 `PAD_BUTTONS`/`PAD_AXES`,
    마우스는 **올리면 선택·누르면 결정** 한 규칙(메뉴·설정·전투·대사창).
  - 인벤토리 **그리드 6×4** + 우측 상세 카드가 호버 정보를 맡는다(툴팁 창을 따로 띄우면
    같은 정보가 두 벌이 된다).
  - 장비 슬롯 명시화 — 장비 탭에 무기·방어구 칸과 수치.
  - 시스템 탭: 저장/불러오기/설정/조작법 — **다시 구현하지 않고** `PauseMenu`에 위임한다.

### 1.4 전투 UI

| 원작 | 개선 |
|---|---|
| 메뉴 5항목 텍스트 | 커맨드 그리드(**공격 / 기술 / 아이템 / 방어 / 도망**) + 커서 애니 |
| (기술 개념 없음) | **기술 서브메뉴** — 습득 스킬 6종, 속성 아이콘(물리/화염/전격), 대상 프리뷰(단일/전체) |
| 상태이상 없음 | 부착 이펙트 아이콘+잔여 턴 표시(DoT/방어 버프/마비 — 01_oop_redesign §5.2). ✅ `StatusChips`(아이콘 아트 대기, §5.10 #37) |
| HP바 양측 상단 고정 | 캐릭터 위 부유 HP바 + 포트레이트 패널 |
| 데미지 무표시 | **데미지 숫자 팝 + 히트스톱**, 약점 속성 색상 구분 |
| 연출 ON/OFF만 | 연출 속도 ×1/×2/스킵, 배틀 로그 사이드패널 — ✅ 둘 다 구현(로그는 `BattleLog` + 좌하단 최근 7줄, 2026-08-30) |

### 1.5 엔딩 연출 (마스터 시나리오 에필로그 반영)

- **메타 엔딩 씬**: CRT 모니터 전환(CRT 스캔라인/휘곡 셰이더) → DOS 프롬프트 타이핑
  (`C:\SIDOL> RUN.BAT` → SYSTEM REPORT ASCII 리포트). 타이핑 속도는 설정에서 조절.
  ✅ **전부 구현(2026-08-30)** — `assets/shaders/crt.gdshader`(휘곡·주사선·색수차·비네트),
  타이핑 속도는 설정 「대사 속도」와 같은 배율을 쓴다.
- **후일담 카드 해금 갤러리**: Q_QUIZ_ALL / Q_QUAN_DONE / Q_HP_ALL 달성분만 크레딧 롤 중
  삽입. 미달성 카드는 실루엣으로 표시(재플레이 동기).
- **멤버 앨범 카드(18차)**: 크레딧룸 멤버 모드는 초상左+이름/역할/명대사/에피소드右.
  초상은 `PortraitLibrary`로 읽고 미납품이면 실루엣 폴백. 스펙 9종
  (`assets/spec/portraits/member_*.json`)이 의뢰 — 납품 오면 자동 교체.
- 엔딩은 단일 메인 분기(마스터 확정) — 분기 로직 없이 카드 추가 방식.

## 2. 타일·스프라이트 크기 정책 — **확정: B안 32px** (2026-08-24)

> 원작 12px는 비표준. 아래는 검토 이력. 최종 결정은 **B안**.

원작 12px 타일은 비표준. 논리 그리드와 렌더 px가 분리돼 있으므로(01_oop_redesign §3.1)
검토 결과 B안 채택 — AI 생성 타깃 해상도로 `spec/*.json`에 주입된다:

| 옵션 | 타일 px | 방법 | 비용 | 품질 | 권장 |
|---|---|---|---|---|---|
| A. 충실 업스케일 | **24 (×2)** | nearest 확대 후 노이즈 보정 | 최저 | 원작감 최대, 도트 거침 | 안전권 |
| B. 표준 리터칭 | **32** | 16px 규격으로 리드로우(원작 도트 참고) | 중 | 현대 인디 RPG 표준 | ★ 권장 |
| C. HD 리메이크 | 48~64 | AI 업스케일(xBRZ/ESRGAN)+손보정 또는 신규 제작 | 최고 | 세대 교체급 | 후순위 |

- **B안 권장 근거**: 16px 그리드는 에셋 생태계(무료 타일셋 보강 가능), Aseprite 워크플로,
  현대 픽셀 RPG 관습에 모두 부합. 캐릭터는 16×24(2셀 폭 논리 유지) 프레임.
- 아트 공급은 **AI 생성**이므로, G-ART 결정값 = 생성 타깃 해상도로서
  [07_ai_asset_pipeline](07_ai_asset_pipeline.md)의 `spec/*.json cell` 필드에 그대로 주입된다.
- 어떤 옵션이든 **코드 변경 0** — `TILE_PX` 상수와 atlas 메타만 교체.
- 폰트: 픽셀 한글 폰트(예: DungGeunMo 계열)로 UI 통일 — 저해상도 아트와 톤 일치.

## 7. 금지선 (원작 정체성 보호)

- 그리드 이동의 자유 이동(free movement)화 ❌ — 원작 감각 손실
- 만담/패러디 톤의 진지화 ❌ — 시나리오 문서의 톤 가이드 따를 것
- 도트 아트를 벡터/3D로 대체 ❌ (C안 선택 시에도 도트 유지)
