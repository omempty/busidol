## 1. 맵 개선 — 층별 재미 요소

원작 맵의 실제 문제: 직선 복도 + 직사각형 방 반복, 왕복 동선, 빈 구역.
리메이크 맵 파이프라인(**Tiled가 권위**) 덕분에 아래 대부분은 코드 수정 없이 편집으로 해결된다.
