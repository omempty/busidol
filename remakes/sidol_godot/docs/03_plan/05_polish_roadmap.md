## 0. 이 문서가 존재하는 이유

Phase 0~9는 대부분 체크되어 있고 관문 14단계가 녹색이다. 그런데 2026-08-26 하루에
조립 결함 8건이 나왔고 **전부 그 녹색 관문을 통과하던 상태**였다.

| 관문 | 보는 층 |
|---|---|
| `tools/validate.gd` | 데이터 참조 — 파일·키·id가 존재하는가 |
| `src/core/self_check.gd` | 시스템 통합 — 로직 단위 규약이 지켜지는가 |
| `tests/smoke_*.tscn` | 시나리오 한 줄기 — 이 조작이 이 결과를 내는가 |
| `tools/check_scripts.gd` | 스크립트가 파싱되는가 |
| **`tools/audit/world_audit.tscn`** | **조립 결과 — 화면에 실제로 뭐가 서 있고 갈 수 있는가** (2026-08-26 신설) |

오브젝트 173종 전량 미렌더 · 전 NPC가 주인공 얼굴 · 몬스터 벽 통과 및 초당 60칸 이동 ·

### 5.4 UI/UX 마감 트랙 (2026-08-28 착수)

캡처 도구 **`tools/dev/ui_shots.tscn`** 신설 — 필드/전투 패널을 실제로 세워 PNG 12장을 남긴다.
`world_audit`은 "화면 밖으로 나갔는가"만 보므로 여백·대비·밀도는 이 도구가 맡는다.
실행: `godot --path . --resolution 960x540 res://tools/dev/ui_shots.tscn -- <출력 폴더>`(창 모드 필요).

**1단계 필드·메뉴 ✅ 해소** — 일시정지·설정·도움말·진행기록에 패널 배경이 아예 없던 것(창마다
껍데기를 따로 만든 탓 → `ModalFrame` 단일 규격), `set_anchors_preset`이 오프셋을 0 크기에 맞춰
남기는 함정(전체화면 요소 9곳), 가방이 앞 9줄만 그려 커서가 안 보이는 줄로 가던 버그,
상점이 마우스 전용이던 것, kind/element 영문 내부값 노출, HUD 힌트 가독성·수량 배지 잘림.

**2단계 전투 ✅ 해소** — 전투 커맨드를 **키보드로 고를 수 없던 것**(Button만 있고 포커스 코드 0곳),
커맨드 분기가 **번역된 문자열 비교**라 영어로 바꾸면 전투가 먹통이던 것(→ 번역 불변 id),
이름 라벨 + 벌거벗은 ProgressBar + `[-]` ASCII 브레이크 게이지 → 카드 규격 + 칸 게이지,
적 카드 폭이 슬롯 간격보다 넓어 2체 이상일 때 겹치던 것.

**3단계 전투 리듬·재미 ⏳ 착수(미완)** — 진단만 해 둔 항목:

| 항목 | 실측/근거 |
|---|---|
| 다중 적 대상 선택 불가 | 공격이 항상 `_first_alive_enemy()`로 자동 타깃. 적이 2체 이상일 때 약점 우선 처치 같은 선택지가 사라진다 |
| 도망 100% 성공 | `&"flee"`가 즉시 필드로 복귀. 리스크가 없어 위기 관리가 성립하지 않는다. 원작 규칙은 `WARMODE.C` 대조 필요 |
| 턴 템포 미계측 | 스모크 실측 1회 액션 ≈ 1.0초(타이밍 링 포함). 층별 평균 턴 수·승률·브레이크 발생률은 아직 측정 도구가 없다 |

P0-01·02는 자동으로 잡혔어야 했다. ✅ **2026-08-26 반영** — `src/core/audit/ui_probe.gd` 신설로 아래가 상시 검사된다:

- **텍스트 오버플로 프루브** — 라벨 최소 크기가 부모 패널을 넘치는지

✅ **2026-08-28 추가** — 필드·전투 밖에 있어 아무도 안 보던 두 곳:

- **메뉴 UI 프루브**(`world_audit._audit_menu_ui`) — 설정·도움말 패널을 **ko/en 두 로케일**로
  세워 화면 이탈 검사. 설정은 행이 늘 때마다 아래로 자라고, 번역은 문자열 길이를 바꾼다.
