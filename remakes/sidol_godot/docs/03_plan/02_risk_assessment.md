# 02. 리스크 평가 및 완화 방안

> 확률(상중하) × 충격(상중하)로 순위화. 각 리스크에 트리거(감지 방법)와 플랜B를 명시.

## R1. SPR 포맷 역공학 [확률: 중 / 충격: **하로 강등** — 2026-08-24 정책 변경]

- **변경 사유**: 에셋 공급을 AI 생성으로 확정([07_ai_asset_pipeline](../02_design/07_ai_asset_pipeline.md))하여
  SPR 해독이 critical path에서 제외됨.
- **새 역할**: 원작 스프라이트 = 생성 품질 참조 자료(DOSBox 캡처 컨택트시트). 해독 성공 시에만
  참고 이미지 정밀도가 올라가는 부수 이득.
- **잔여 리스크**: 없음(critical path 기준). 컨택트시트 품질이 나쁘면 프롬프트 참조 정밀도만 저하.
- **선제 조치**: 유지 — Phase 1은 PCX(HUD)와 최소 대체 타일로 진행 가능.

## R2. AI 바이브 코딩 특유 리스크 [확률: 상 / 충격: 중]

| 세부 리스크 | 완화 |
|---|---|
| 환각 API/존재하지 않는 함수 | Godot 버전 고정, 모든 작업의 스모크 실행 강제(06_ai_dev §3) |
| 절반짜리 대규모 수정 | 파일 수 상한, 인터페이스 선승인 규칙 |
| 세션 간 맥락 단절 | **문서가 단일 진실원천** — 코드 변경 시 같은 커밋에 docs 갱신 의무 |
| 스타일 표류 | 네이밍 고정표 + gdformat CI |
| "테스트 통과를 위한" 우회 구현 | Validator/스모크는 CI 전용 결과만 인정, 로컬 주장 불인정 |
| 과설계(불필요 추상화 폭발) | 로드맵 Phase 밖의 레이어 추가 금지, PR 단위 파일수 리뷰 |

## R3. 시나리오 개편 중 원작 정체성 손실 [확률: 중 / 충격: 상]

- **내용**: 만담·패러디·자조 개그("3류 공포물", 농구, 짜장면)가 정리되면서 무미건조해짐.
- **완화**:
  - 스토리바이블에 톤 코드 명시(04_scenario/02 §1), 개편 집필 시 원문 인용 비율 가이드
  - dialogue.json의 `@t숫자` 참조 유지 → 원문과 신규 대사 혼용 가능
  - 외부 플레이테스트(MS5 전)에서 유머 체감 설문

## R4. 원작 결함 이식 여부 판단 지연 [확률: 하 / 충격: 중]

- DP 미반영 데미지, 전투 후 무조건 보상, MEHURRY 쓰레기값 등.
- **완화**: G-FAITH 게이트에서 항목별 결정표 작성(유지/수정). DamageCalculator에
  `faithful_mode: bool` — 두 모드 모두 테스트. 결정 지연 시 기본값=개선 모드.

## R5. 팔레트 인덱스 의존 이펙트 재현 [확률: 하 / 충격: 하]

- Window 색조/페이드가 인덱스 산술 → Godot RGBA에서 의미 상실.
- **완화**: 이미 설계에서 셰이더/Tween으로 대체 확정(01_analysis/03 §8).
  시각 검증은 DOSBox 녹화본과 나란히 비교.

## R6. Johab 텍스트 오염 [확률: 상(이미 발생) / 충격: 하]

- PROLOG.CAP 일부 행이 다른 인코딩 흔적으로 깨져 있음.
- **완화**: SE1 단계에서 문맥 복원 + 복원 불가 행은 `[원문 불명]` 마커.
  게임 데이터(TALK.TXT)는 깨짐 없음 확인 완료.

## R7. 설정 불일치로 인한 개편 혼선 [확률: 중 / 충격: 하]

- 중앙통제실 3층 vs 5층, 약품 전압 수치 혼재.
- **완화**: 스토리바이블 §8에 통일안 확정(G4=5층, G5=표준표). 개편 문서가 유일 권위.

## R8. 스코프 크리프 (현대화 욕구 폭주) [확률: 상 / 충격: 상]

- Q1~Q10, BGM 제작, 도전과제 등 추가 욕구가 MS 일정을 압도.
- **완화**: 모든 신규 아이디어는 04_uiux §6 체크리스트에 적립 후 **Phase 경계에서만**
  스코프 편입 결정. MVP 정의(MS3)는 불변. "Phase 밖 레이어 추가 금지" 규칙과 동근원.

## R9. 저해상도 아트 × 현대 UI 위화감 [확률: 중 / 충격: 중]

- 24/32px 업스케일 아트에 고해상도 폰트/패널이 어울리지 않을 수 있음.
- **완화**: UI도 픽셀 톤 통일(비트맵 한글 폰트, 9-slice 픽셀 프레임). G-ART 결정 때
  HUD 프레임(TEST_F.PCX) 리터치 포함 여부 동시 결정.

## R10. 검증 환경(DOSBox) 의존 [확률: 하 / 충격: 하]

- 원작 감각 비교·SPR 플랜B에 DOSBox 필요.
- **완화**: Phase 0에 DOSBox+sidol.exe 실행 확인, 녹화본 확보. 보존/BSD.ARJ도 압축해제 검증.

## R11. AI 생성 에셋의 품질·일관성 붕괴 [확률: 상 / 충격: 중]

- **내용**: 배치마다 캐릭터 외형이 달라짐, 팔레트 이탈, 프레임 경계 오염(비주얼) /
  루프 이음새 끊김, 음량 불균형, 무드 이탈(오디오).
- **트리거**: 동일 캐릭터 재생성 3회 연속 불합격, Validator 차단률 50% 초과 지속.
- **완화**:
  - 계약서+게이트 구조([07_ai_asset_pipeline](../02_design/07_ai_asset_pipeline.md)): 스펙 위반은
    게임 유입 자체가 불가 — 품질 문제가 플레이어 도달 전 차단됨
  - `style_bible.md` + `palette_master.json` 잠금, 캐릭터별 고정 서술 토큰(prompt_vars.subject)
  - 원작 컨택트시트를 style_refs로 상시 첨부
  - **재생성 예산제**: 에셋당 N회 시도 한도 → 초과분은 수동 보정(Aseprite/오디오 편집)으로 전환
- **수용 기준**: "완벽한 생성"이 아니라 "게이트 통과율" 관리. 통과만 되면 채택.

## R12. AI 생성 BGM의 원작 감성 미달 [확률: 중 / 충격: 하]

- **내용**: 칩튠 6곡이 "그럴듯하지만 1995 DOS RPG가 아닌" 느낌으로 나올 수 있음.
- **완화**: bgm.json에 mood_tags+원작 참조 서술(원작 멜로디 배열 힌트) 명시, 감동 컷신 곡은
  마스터 시나리오 톤 커브와 함께 인간 리뷰 필수. 최악 시 해당 곡만 외부 위탁 폭포백.

## 리스크 레지스터 운영

- 매 Phase 종료 시 본 문서를 갱신(발생한 리스크는 사례로 기록).
- 새 리스크 발견 시 즉시 추가하되, 대응은 "문서화 → 게이트에서 결정" 순서 준수.
