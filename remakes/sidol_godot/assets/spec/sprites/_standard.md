# 스프라이트 표준 규격 (Sprite Standard v1)

> 모든 캐릭터/NPC/몬스터 시트에 적용. 그래픽 LLM 생성·기존 도트 이관 공통.
> 상위 규칙: assets/style_bible.md · 스키마: assets/spec/sprites/*.json

## 1. 셀 규격

| 항목 | 표준 | 비고 |
|---|---|---|
| 셀 크기 | **128 × 128px** (유일 표준) | 폭=높이 셀은 컨테이너일 뿐, 캐릭터는 세로형 |
| 캐릭터 실높이 | 96 ~ 118px (셀의 75~92%) | 예제 시트 기준 ~110px |
| 캐릭터 실폭 | ≤ 80px (높이의 ~0.6배) | 세로형 비율 4:7 내외 |
| 정렬 | 발바닥 = 셀 하단 중앙, 상단 10~20% 여백 | 앵커 일관이 프레임 떨림 방지의 핵심 |
| 게임 내 크기 | 렌더 scale 메타로 조절 (기본 0.75 → 실횻높이 ~80px ≈ 2.5타일) | 아트 해상도와 게임 크기 분리 |

- 기존 24×24 원작 도트 이관 시: 4배 nearest 업스케일(96px)로 표준 셀에 배치
  (`tools/convert/standardize_original_sheet.py` 참조).

## 2. SD 스타일 (스타일 바이블 캐릭터 규칙 구체화)

- 머리:몸 ≈ **1 : 1.2** (큰 머리 SD)
- 실루엣 부드럽게, 원작 구도 유지(이관 시) / 신규 생성은 원작 포즈 어휘 차용
- 눈은 얼굴 하단 1/3에 크게 — SD 캐릭터 판별 포인트

## 3. 프레임 규격 (가변 수용)

| 애니 | 프레임 | 내용 |
|---|---|---|
| walk_down/up/left/right | **최소 2, 권장 4** (가변) | 4프레임 사이클: 접지→착지중→도약(다리 교차)→중간 |
| idle_down/up/left/right | 2 (고정) | 숨쉬기: 어깨/가슴 1~2px 상하 |

- **프레임 수는 애니마다 달라도 된다** — 런타임은 메타의 frames 수를 그대로 읽음.
- 단, 같은 애니 내 프레임 간 캐릭터 일관(머리 크기·의상·색 배치)은 절대 유지.

## 4. 레이아웃 (표준 행 배치)

```
행 0~3 : walk_down / walk_up / walk_left / walk_right
행 4~7 : idle_down / idle_up / idle_left / idle_right
열     : 좌→우 프레임 순서 (시트 폭 = 4열 기준 512px, 프레임 수가 적으면 빈 셀은 완전 투명)
```

## 5. 색·연출 규칙 (스타일 바이블 준수)

- 배경: **마젠타 #FF00FF 단색** (누끼 예약색). 캐릭터-마젠타 사이 혼색/반투명/AA 금지
- 캐릭터 내부 검정(눈·입·틈): 투명 금지 → 아주 어두운 남색(#0A082E 방향)
- 명암: 색당 4~6단계 밴딩 / 그림자는 남보라(#3A285C 방향) 색조 / 하이라이트 웜톤
- 외곽선: 1px 다크 아웃라인(짙은 남색), 순수 블랙 금지
- 팔레트: 원작 파생 색 세트 + 따뜻한 JRPG 톤. 형광/파스텔 붕괴/EGA 원색 금지
- SD 비율: 머리:몸 1:1.2

## 6. 납품 검증

`python tools/convert/validate_retouch_sheet.py <납품.png>` — 크기/투명도/마젠타/
도트 bbox/픽셀 편차 자동 판정. 통과본만 뷰어 검수 → 패킹.
