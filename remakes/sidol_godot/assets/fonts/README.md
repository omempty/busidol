# UI 폰트

`src/autoload/ui_theme.gd`가 이 폴더에서 아래 순서로 찾아 루트 Window 테마에 건다.
파일만 이 이름으로 넣으면 코드 변경 없이 전 UI에 적용된다.

```
assets/fonts/ui_pixel.ttf     ← 픽셀 한글 폰트(있으면 최우선. 안티에일리어싱 자동 해제)
assets/fonts/ui_main.ttf      ← 외곽선 폰트(현재 D2Coding · OFL). 지금 적용 중인 것
```

**현재 상태**: `ui_main.ttf` = D2Coding(OFL) 번들 — 고지는 [LICENSE-D2Coding.md](LICENSE-D2Coding.md).
2026-08-28 이전에는 시스템 **굴림체**로 폴백하고 있었는데 MS 라이선스라 배포본에 담을 수 없었다
(개발 PC에서만 보이던 글꼴). `ui_pixel.ttf`가 들어오면 그쪽이 자동으로 우선한다.

없으면 시스템에 설치된 픽셀 계열 한글 폰트로 폴백하고(개발 PC 한정),
그것도 없으면 Godot 기본 폰트를 쓴다. 어느 경로를 탔는지는 부팅 로그
`[ui_theme] ...` 한 줄로 확인할 수 있다.

## 아직 픽셀 폰트가 아닌 이유

04_uiux §2는 "픽셀 한글 폰트(DungGeunMo 계열)로 UI 통일"을 정했다. 이 PC에는 픽셀 한글
폰트가 설치돼 있지 않아(설치 폰트를 전수 조사) 우선 OFL 외곽선 폰트로 배포 가능한 상태를
만들어 둔 것이다. 아래에서 하나 구해 `ui_pixel.ttf`로 넣으면 교체된다.

## 픽셀 폰트 후보

| 폰트 | 성격 | 라이선스 |
|---|---|---|
| **둥근모꼴 (DungGeunMo)** | 도스/윈도 초기 감성의 표준 픽셀 한글. 이 프로젝트 톤에 가장 가깝다 | 무료 배포 허용으로 알려져 있음 — **배포 전 원 배포처 조건 확인 필요** |
| **Galmuri (갈무리)** | 크기별 변형(9/11/14 등)이 갖춰진 현대 픽셀 한글 | SIL Open Font License로 알려져 있음 — 확인 필요 |
| **NeoDunggeunmo (네오둥근모)** | 둥근모 계열 확장 | 확인 필요 |

**굴림체·돋움체는 넣지 말 것.** 비트맵 힌팅이 있어 픽셀처럼 보이지만 Microsoft
라이선스라 재배포할 수 없다. `ui_theme.gd`의 시스템 폴백 목록 뒤쪽에만 두어
개발 중 미리보기로 쓴다.

## 크기 주의

픽셀 폰트는 임베드된 크기(보통 8·9·11·12·16)에서만 또렷하다. UI 코드가 쓰는 크기는
9~28이 섞여 있으니, 폰트를 넣은 뒤 대화창·HUD·전투 메뉴를 눈으로 확인하고
어긋나는 곳의 `font_size` 오버라이드를 폰트의 임베드 크기에 맞춰 조정한다.
