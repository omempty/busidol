# 스타일 바이블 (Style Bible)

> 모든 AI 생성 에셋(이미지·오디오) 프롬프트에 주입되는 최상위 창작 규칙.
> 스펙 JSON과 함께 읽힌다: `spec/**/*.json` (docs/02_design/07_ai_asset_pipeline.md)

## 스타일 타깃 (2026-08-24 확정 — 최상위 지시)

**원작(1995) 도트를 베이스로, 쯔바이!!·나르실리온·악튜러스 계열의
후기 클래식 JRPG 픽셀 아트 톤으로 격상시킨다.**

| 항목 | 지향 |
|---|---|
| 전체 인상 | 어두운 VGA 레트로 → **따뜻하고 채도 있는 JRPG 필드**(악튜러스풍 배경 밀도) |
| 타일 | 단색+선 → **스토리텔링 디테일**: 금 간 바닥, 책상 위 소품, 패널 이음새. 타일당 색 ≥10 |
| 캐릭터 | **2.5~3등신 SD 클래식 JRPG 체형**(쯔바이/악튜러스/나르실리온풍). 큰 머리와 명확한 표정 실루엣, **셀을 꽉 채우는 묵직한 볼륨감**(실높이 약 80~88% 면적 점유, 왜소한 24px 방치 금지). 내부 명암 4~6단계 밴딩 |
| 몬스터 | **2.5~3등신 SD 체형 + 셀(128×128)을 꽉 채우는 묵직하고 밀도 있는 볼륨감**(왜소하지 않고 굵직한 덩치감과 그로테스크한 존재감) |
| 명암 | 하이라이트~그림자 최소 4~6단계 계단식 밴딩. 그림자는 검정 대신 **남보라(#3A285C / #251840) 색조 그림자** |
| 외곽선 | 1px 다크 아웃라인 유지, 순수 블랙 금지 — **짙은 남색(#0A082E / #10082E) 또는 짙은 암갈색** |

- 원작 참조와의 관계: **구도·실루엣·배치는 원작(`originals_ref/bmp_spr/`)에서,
  질감과 색 감각은 JRPG 타깃에서** 가져온다. 단순 확대·재채색은 반려 대상.
- 스케일업 & 리터칭: 기존 24×24px 소형 스프라이트를 스케일업/리터칭할 때도 **2.5~3등신 SD JRPG 체형과 셀을 넉넉히 채우는 볼륨감**을 필수로 부여한다.

## 픽셀 아트 규칙 (100% Pure Dot Matrix)

- 3D CGI 렌더링, 벡터 그래픽(SVG), 수채화, 일러스트 브러시 질감 절대 금지
- 캔버스 확대 시 각진 픽셀 도트(Pixel Grid)가 한 땀 한 땀 뚜렷하게 보이는 정통 도트 그래픽
- 안티에일리어싱(AA) 금지 / 그라데이션 금지(색당 4~6단계 계단식 밴딩과 체커보드 디더링으로 표현)
- 외곽선 1px 다크 아웃라인(순수 블랙 대신 짙은 남색/갈색 #0A082E), 명암은 색당 4~6단계
- 배경은 완전 투명(alpha=0) 또는 단색 마젠타 #FF00FF — 흰색/체커보드 배경 금지

## 팔레트 잠금 + 확장 절차

- 기본: `palette_master.json`(원본 DEFAULT.PAL 유래, 256색 hex)의 색만 사용
- JRPG 톤 구현을 위한 **확장 팔레트 +64색**(따뜻한 중간톤 위주) 신설 가능 —
  사용 전 본 문서 개정으로 확정하고 `palette_extended.json`으로 별도 관리

## 시대 톤

- 1995 DOS VGA 감성을 베이스로 하되 현대적 가독성과 따뜻한 색조로 격상
- 무드 태그 체계는 마스터 시나리오 톤 커브(§1.2)를 따른다:
  `레트로 / 개그(B급 공대 유머) / 모험 / 감동 / 메타픽션`

## 캐릭터 일관성

- 캐릭터별 **고정 서술 토큰**(`prompt_vars.subject`)을 정의하고 모든 배치에서 재사용
- 토큰 변경 = 캐릭터 리디자인으로 간주, 관련 에셋 전량 재생성 대상

## 오디오 규칙

- BGM: FM/PSG 칩튠 음색(square/triangle/noise), 실악기 금지, 루프 심리스 필수
- Voice(원작 VOC): 생성하지 않고 원본 변환본 사용
