# 먼저 읽기 — 그래픽 작업 지시서

너는 1995년 한국 공대 배경 캠퍼스 호러 JRPG **「BSD 시돌이의 모험」** 리메이크의
그래픽 담당이다. 이 폴더(`assets/raw/llm/`)가 네 작업 공간 전부다.

## 0. 절대 규칙

- **한 번에 한 개씩** 작업한다. 배치 생성 금지.
- 각 패키지의 `prompt.md`가 **구속력 있는 계약**이다. 이 문서보다 그쪽이 우선한다.
- `prompt.md`의 규격(캔버스 크기·그리드·행별 프레임 수)은 **한 픽셀도 바꾸지 않는다.**
  크기가 어긋나면 자동 검증이 반려한다.
- 이 폴더 밖의 파일을 읽거나 고치지 않는다.

## 1. 무엇부터 하나

지시가 따로 없으면 이 순서로 진행한다. 게임에 **실제로 비어 있는** 순서다.

| 순위 | 대상 | 상태 |
|---|---|---|
| 1 | `portraits/*` 16종 | 대화창 초상 전무 |
| 2 | `effects/*` 5종 | 전투 이펙트 전무 — 물리·화염·전격이 전부 같은 점 파티클로 뜬다 |
| 3 | `battle_cuts/*` 5종 | 원작의 전투 대형 컷(리미티드 애니메이션)이 리메이크엔 없다 |
| 4 | `keyart/*` 6종 | 컷신 일러스트 전무 |
| 5 | `monsters/` 나머지 8종(보스 2 포함) | 아직 시트가 없는 신규 종 |
| 6 | `items/*` 40종 | 없으면 인벤토리에 색 상자 + 글자 |

## 2. 작업 절차

### ① 읽기

작업할 패키지 폴더에서:

- `prompt.md` — 계약. 전문을 읽는다.
- **`prompt.md`의 "입력 (첨부)" 목록에 적힌 파일 전부.** 그 목록이 첨부물의 유일한 근거다 —
  같은 그림을 패키지마다 복사하지 않으려고 공용 참조는 **카테고리 루트에 1부**만 둔다.
  목록의 `../foo.png`는 한 단계 위(카테고리 루트) 파일이라는 뜻이다.

### ② 이미지의 역할을 구분한다 (중요)

| 파일 | 역할 |
|---|---|
| `<id>_source.png` · `orig_this_scene.png` | **신원·구도 근거** — 누구인지/무엇인지. 바꾸지 마라 |
| `orig_portrait_*.png` · `orig_scene_*.png` · `orig_enemy_*.png` | **화풍 근거** — 원작 그림. 선 굵기, 음영 단계 수, 색 배분을 계승한다 |
| `style_ref.png` · `tone_anchor.png` · `scale_ref.png` | **크기·정렬·채도 기준** — 게임 내 도트 |
| `palette_swatch.png` · `subpalette.png` | 사용 가능한 색 |
| `grid_template.png` | **그 위에 그리는 빈 격자.** 마젠타 선 = 셀 경계 — 다 그린 뒤 **전부 지운다** |
| `grid_guide.png` | 행 이름·프레임 수를 적은 **설명 그림. 참고만 한다** — 캔버스 크기가 일부러 다르다 |

**규칙 문장보다 첨부 그림이 우선한다.** 원작 그림을 보고 그 화풍으로 그린 뒤
해상도와 완성도만 격상하는 것이 이 프로젝트의 계약이다. 자유 재해석이 아니다.

### ③ 그리기

`prompt.md`의 "출력 규격"과 "스타일 타깃"을 그대로 따른다. 공통 함정:

- 안티에일리어싱 금지 · 그라데이션은 밴딩 단계로 · **고유색 48색 이하**
  (실납품이 16,000~50,000색으로 온 적이 있다 — 그건 도트 그림이 아니다. 색을 먼저 정하고 찍어라)
- **격자 안내선·라벨 글자를 남기지 마라.** 흐리게 남겨도 자동 검사가 직선으로 잡아낸다
  (`grid_guide.png`의 애니 이름을 그림에 옮겨 그린 납품이 실제로 있었다)
- 그림자에 순수 검정 금지 → 남보라 계열
- 외곽선에 순수 블랙 금지 → 짙은 남색 계열
- 배경은 **완전 투명**. 불가하면 **마젠타 `#FF00FF` 단색** — 혼색·반투명·AA 금지
  (마젠타에 AA가 섞이면 누끼가 깨져 반려된다)
- 스프라이트 시트는 **셀 하단 중앙 정렬**, 빈 셀은 완전 투명

### ④ 저장

```
10_submitted/<카테고리>/<id>_v1.png
```

- `<카테고리>` = `portraits` · `keyart` · `monsters` · `npcs` · `items` · `effects` · `battle_cuts` · `sprites` 중 하나
- `<id>` = **패키지 폴더 이름과 글자 단위로 동일**. 어긋나면 심사 보드가 원본과 짝을 못 짓는다
- 재납품은 `_v2`, `_v3` — 번호를 올린다
- 폴더는 이미 만들어져 있다

예: `10_submitted/monsters/c_bug_v1.png`

### ⑤ 보고

납품 후 3줄 이내로: 무엇을 그렸는지 · 원작에서 무엇을 계승했는지 · 규격 준수 여부.

## 3. 반려를 받으면

`10_submitted/_feedback/<카테고리>/<파일>.md`에 재요청 패키지가 생성된다.
그 안에 **원본 의뢰문 + 반려 사유 + 자동 검증 결과 + 다음 버전 번호**가 다 들어 있다.
그 파일을 읽고, 원래 첨부 이미지를 다시 보고, 지정된 버전 번호로 재납품한다.

## 4. 하지 말 것

- 다른 패키지의 `prompt.md`를 섞어 읽기
- 그리드·캔버스 크기 임의 변경("더 예쁘니까" 포함)
- 없는 종·씬을 새로 만들기
- `10_submitted/` 밖의 파일 생성·수정·삭제
- 여러 개를 한 번에 그리기
