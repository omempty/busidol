# [공통 지시] BSD 시돌이의 모험 — 도트 스프라이트 제작 규약

아래는 이 대화에서 만들 **모든 그림**에 적용되는 규약이다. 이후 내가 개별 시트를
요청하면 이 규약을 그대로 지킨 채 그려라. 규약과 개별 요청이 충돌하면 **개별 요청의
숫자(캔버스 크기·프레임 수)** 가 우선이고, 화풍은 이 규약이 우선이다.

## 작품
1995년 한국 공대를 배경으로 한 캠퍼스 호러 JRPG의 리메이크. 원작은 1995년 DOS VGA
게임이고, 리메이크는 그 도트를 **후기 클래식 JRPG 픽셀 아트**(쯔바이!!·나르실리온·
악튜러스 계열)로 격상시킨다. 단순 확대·재채색은 실패다.

## 최상위 창작 규칙 (스타일 바이블 — 아래 모든 지시보다 우선)

### 스타일 타깃 (2026-08-24 확정 — 최상위 지시)

**원작(1995) 도트를 베이스로, 쯔바이!!·나르실리온·악튜러스 계열의
후기 클래식 JRPG 픽셀 아트 톤으로 격상시킨다.**

| 항목 | 지향 |
|---|---|
| 전체 인상 | 어두운 VGA 레트로 → **따뜻하고 채도 있는 JRPG 필드**(악튜러스풍 배경 밀도) |
| 타일 | 단색+선 → **스토리텔링 디테일**: 금 간 바닥, 책상 위 소품, 패널 이음새. 타일당 색 ≥10 |
| 캐릭터 | **2.5~3등신 SD 클래식 JRPG 체형**(쯔바이/악튜러스/나르실리온풍). 큰 머리와 명확한 표정 실루엣, **셀을 꽉 채우는 묵직한 볼륨감**(실높이 약 80~88% 면적 점유, 왜소한 24px 방치 금지). 내부 명암 4~6단계 밴딩 |
| 몬스터 | **2.5~3등신 SD 체형 + 셀(128×128)을 꽉 채우는 묵직하고 밀도 있는 볼륨감**(왜소하지 않고 굵직한 덩치감과 그로테스크한 존재감) |
| 명암 | 하이라이트~그림자 최소 4~6단계 계단식 밴딩. 그림자는 검정 대신 **남보라(#3A285C / #251840) 색조 그림자** |
| 외곽선 | 1px 다크 아웃라인 유지, 순수 블랙 금지 — **짙은 남색(#0A082E / #10082E) 또는 짙은 암갈색** |

- 원작 참조와의 관계: **구도·실루엣·배치는 원작(`originals_ref/bmp_spr/`)에서,
  질감과 색 감각은 JRPG 타깃에서** 가져온다. 단순 확대·재채색은 반려 대상.
- 스케일업 & 리터칭: 기존 24×24px 소형 스프라이트를 스케일업/리터칭할 때도 **2.5~3등신 SD JRPG 체형과 셀을 넉넉히 채우는 볼륨감**을 필수로 부여한다.

### 픽셀 아트 규칙 (100% Pure Dot Matrix)

- 3D CGI 렌더링, 벡터 그래픽(SVG), 수채화, 일러스트 브러시 질감 절대 금지
- 캔버스 확대 시 각진 픽셀 도트(Pixel Grid)가 한 땀 한 땀 뚜렷하게 보이는 정통 도트 그래픽
- 안티에일리어싱(AA) 금지 / 그라데이션 금지(색당 4~6단계 계단식 밴딩과 체커보드 디더링으로 표현)
- 외곽선 1px 다크 아웃라인(순수 블랙 대신 짙은 남색/갈색 #0A082E), 명암은 색당 4~6단계
- 배경은 완전 투명(alpha=0) 또는 단색 마젠타 #FF00FF — 흰색/체커보드 배경 금지

### 팔레트 잠금 + 확장 절차

- 기본: `palette_master.json`(원본 DEFAULT.PAL 유래, 256색 hex)의 색
  — 주의: 이 파일의 값은 원본 그대로라 **6비트(0~63)** 다. 화면·의뢰문의 hex는
  8비트이므로 `<< 2`(0x3F → 0xFC)로 맞춰 비교한다.
- JRPG 톤 구현을 위한 **확장 팔레트 +64색**을 2026-09-08 확정했다:
  `palette_extended.json` — 손으로 고른 목록이 아니라 **설치된 리메이크 아트에서 실측**한
  마스터 밖 사용 빈도 상위 64색이다(`tools/convert/make_palette_extended.py`로 다시 굽는다).
- 따라서 허용 색 = **마스터 256 + 확장 64**. 그 밖의 색은 반려 사유다.
  아트가 바뀌어 확장 팔레트가 낡으면 색을 임의로 늘리지 말고 위 도구로 다시 구워 확정한다.

### 시대 톤

- 1995 DOS VGA 감성을 베이스로 하되 현대적 가독성과 따뜻한 색조로 격상
- 무드 태그 체계는 마스터 시나리오 톤 커브(§1.2)를 따른다:
  `레트로 / 개그(B급 공대 유머) / 모험 / 감동 / 메타픽션`

### 캐릭터 일관성

- 캐릭터별 **고정 서술 토큰**(`prompt_vars.subject`)을 정의하고 모든 배치에서 재사용
- 토큰 변경 = 캐릭터 리디자인으로 간주, 관련 에셋 전량 재생성 대상

### 오디오 규칙

- BGM: FM/PSG 칩튠 음색(square/triangle/noise), 실악기 금지, 루프 심리스 필수
- Voice(원작 VOC): 생성하지 않고 원본 변환본 사용

## 그리기 규칙 (전부 필수)
- **순수 픽셀 아트만.** 3D 렌더·벡터·수채/유화 질감·사진 합성 금지. 확대하면 각진
  도트가 한 칸씩 보여야 한다.
- **안티에일리어싱 금지, 그라데이션 금지.** 명암은 색당 4~6단계의 계단식 밴딩으로.
- **반투명 픽셀 0%.** 픽셀은 켜지거나 꺼진다. 경계를 부드럽게 흐리지 마라.
- **1px 다크 아웃라인.** 순수 검정(#000000) 금지 — 짙은 남색(#0A082E) 계열을 쓴다.
- **그림자는 검정이 아니라 색조 그림자**(남보라 #3A285C 계열).
- **고유색 48색 이하.** 실제 납품이 16,000~50,000색으로 온 적이 있다 — 그건 도트가 아니다.
- **배경은 완전 투명(alpha=0).** 투명을 못 만들면 **단색 마젠타 #FF00FF**로 채운다
  (혼색·반투명·경계 흐림 금지 — 정확히 그 값이어야 지울 수 있다).
- 색은 아래 팔레트 안에서 고른다(모자라면 이 색들 사이의 중간톤까지만 허용):
  `#00001F #512842 #525563 #284882 #508CD2 #305DAE #121E3C #B5A6A7 #0A082E #2E3739 #493B4C #9F0F2E #C8202C #183038 #8C101C #A0DCFF #286068 #8CDCE0 #40FFDC #F8F4E8 #82789C #203878 #DCAA96 #F05046 #FAFAFF #1A162A #010037 #FEC7A9 #C49E81 #B28F75 #EDEFFC #FBD2BC #764A62 #896E5A #E5BA97 #28305E #F25524 #24D9F2 #245DF2 #A5BEFF`

## 캔버스에 그리면 안 되는 것
- 글자·숫자·로고·서명·워터마크·설명 라벨 — **애니메이션 이름이나 프레임 번호 포함**
- **격자선·안내선·셀 경계선.** 셀은 눈에 보이지 않는 규칙일 뿐이다. 선을 그으면 반려다
- 액자·테두리·둥근 모서리 마스크·배경에 깔린 그림자
- 요청한 것 외의 물건(단품만)
- **공격 프레임의 소품·무기·투사체.** 공격은 몸의 동작으로만 표현한다. 날아가는 물체·
  파편·충격파를 셀 안에 그리면 캐릭터 실루엣과 겹쳐 규격 검사가 어긋나고, 게임에서는
  그 칸이 캐릭터로만 잘려 물체가 몸에 달라붙어 보인다. 타격 이펙트는 따로 만든다.

## 출력 형식
- **PNG 1장**, 요청한 캔버스 크기와 **픽셀 단위로 정확히** 일치.
- 크기를 정확히 못 맞추겠으면 **가로세로 비율만이라도 정확히** 지키고, 셀 격자가
  균등하게 나뉘도록 그려라(내가 리샘플로 교정한다).
- 여러 장으로 쪼개 그리지 마라. 한 장의 시트다.
