## 2. 반려 사유

1. **타일 색 밀도 미달**: 3.1종/셀은 원작(8.4종/12px!)보다도 낮음. 32px에서는
   JRPG 풍 디테일(금 간 바닥, 소품, 명암 밴딩)로 최소 **10종 이상** 요구.
2. **스타일 타깃 변경 적용**: 신규 확정 스타일(`style_bible.md` §스타일 타깃)에 따라
   쯔바이·나르실리온·악튜러스 톤으로 전면 재검토 필요.
   - 따뜻한 색조, 색조 그림자(블랙 금지), 짙은 남색/갈색 외곽선
   - 원작 구도(bmp_spr/) 유지 + JRPG 질감 추가

## 3. v2 재납품 요구사항 체크리스트

- [ ] 타일당 고유색 ≥10, 명암 4~6단계 밴딩
- [ ] 외곽선 = 짙은 남색/갈색(순수 블랙 금지)
- [ ] required_tiles 25종 전부, 종별 원작 참조(tile/ 105장) 선행 열람
- [ ] 캐릭터: 실루엣 유지 + JRPG 톤 리터칭 (v1에서 파생 가능)
- [ ] 6bit 스케일 준수(이미 교정된 산출물 재사용 가능)
- [ ] character_bible.html / tile_viewer.html 갱신 포함

## 4. 유지 사항

- 6bit→8bit 교정본 PNG는 v2 작업 시 참조용으로 보존 가치 있음(색 사용 습관 파악용).
