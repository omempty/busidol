# 그래픽 AI 에이전트 작업 브리프 (Asset Agent Brief)

> 수신: 그래픽 생성 AI 에이전트. 이 문서 하나만 읽으면 작업을 시작할 수 있어야 한다.
> 최종 갱신: 2026-08-24 · G-ART **B안 확정(타일 32px / 캐릭터 프레임 64×64)**

## 0. 읽을 순서

1. 이 문서
2. `assets/style_bible.md` — 창작 규칙(절대 준수)
3. `assets/originals_ref/` — **★원작 실제 그래픽 필수 열람**
   - **`bmp_spr/` 최우선 — 원작 .SPR 완전 해독 산출(62파일·935프레임 BMP+컨택트시트 PNG)**
     - `i/`(72): 필드 주인공·몬스터 워크 시트 / `tile/`(105): 원작 타일 전량
     - `obj/`(173)·`objobj/`: 오브젝트 / `eventer/`(40): 배회 NPC
     - `monster/`(72)·`mutant/`·`robo/`·`e1~e8/`: 몬스터·전투 도트
     - `a1~a5/ d1~d4/ fire/ mboom/ rboom/`: 공방·폭발 연출 프레임
     - `hong/ hwang/ nam/ na/ wkim/ gwon/`: 교수 초상 원화
   - `bmp/`: 원작 PCX 전체 73장(BMP) — 배경·얼굴·HUD·연출 원화
   - `*.png`(13장 선별본)
   - **생성 전 반드시 같은 종류의 원작을 먼저 열람**할 것.
     예: 필드 캐릭터 → `i/`, 타일 → `tile/`, 공격 연출 → `attack1~6.bmp` + `a1~a5/`
     이 자료들의 색감·구도·밀도가 "원작 느낌"의 기준점이다.
4. `assets/palette_master.json` — 사용 가능한 256색 hex 잠금 팔레트
5. `assets/spec/sprites/*.json` — 작업 대상 계약서(아래 §2 목록)
6. 필요 시 참고: `docs/04_scenario/02_story_bible.md`(인물 성격), `docs/01_analysis/03_data_format_spec.md`(원작 구조)

> 기술 노트: 원작 .SPR은 압축 포맷으로 확인되어 직접 추출은 보류 중이다.
> 따라서 위 PCX 수출본 + 향후 DOSBox 화면 캡처가 원작 도트의 유일한 시각 자료다.
> 스타일 판단은 반드시 이 자료 기준으로 한다.

## 3. HTML 리뷰 도구 2종 (에이전트 산출물에 포함)

생성 결과를 사람/LLM이 검수할 수 있도록 다음 **단일 파일 HTML** 뷰어를 함께 만들어
`assets/gen/viewers/` 에 저장한다. 외부 CDN·네트워크 의존 금지(file://에서 동작).
PNG 임베드는 base64 data-URI 인라인을 권장한다(fetch 제한 회피).

### 3.1 `character_bible.html` — 캐릭터 바이블(사전)
- 좌측: 캐릭터 목록(asset_id), 우측: 선택 캐릭터의 시트 전체 프레임 격자 렌더(canvas)
- 각 캐릭터마다 표기: **고정 서술 토큰**(§4), 버전(v1/v2…), 팔레트 준수 여부
- 애니메이션 행 강조(walk/idle 구간 가이드) + 프레임별 확대 보기
- 목적: 배치 간 일관성 검토, 사람 승인 서명용 화면

### 3.2 `tile_viewer.html` — 타일 뷰어
- 아틀라스 PNG 로드 → 32px 격자 오버레이, 마우스 호버 시 ID/atlas 좌표 표시
- 줌(×1~×8), 지면/오브젝트 행 필터
- **multi_tile_objects 커버리지**: 각 사물의 조각 수(w×h)가 전부 존재하는지 체크리스트
- terrain border_match 샘플 조합(코너 4종) 미리보기 모드

## 3.5 멀티타일 사물 규칙 (2026-08-24 확정)

> 큰 사물을 한 타일에 다 몰아넣으면 안 된다 — 반드시 여러 타일에 쪼개서 표현.

- 스펙: `multi_tile_objects` 배열에서 `{id, w, h}`로 조각 격자 정의.
  예: 자판기 = w2×h3 = 64×96px 이미지 → 패커가 32px 조각 6개로 분할.
- 생성 프롬프트: **"전체 사물을 (w×32)×(h×32) 해상도로 그려라"** — 조각 단위로 나눠 그리지 말 것.
- 명명: `vending_machine_tl/tr/bl/br` 등 위치 접미사는 패커가 자동 부여.
- 지형(border_match) 타일과 마찬가지로, 인접 조각끼리 이어져야 함.

| **슬로모션** | 마지막 타격(적 다운) | ×0.3 for 0.5s |

`validate_sprite.py`(메인 개발 측 제공 예정)가 자동 검사:
- 캔버스 = cell×grid 정확 일치 · 프레임 경계 침범 없음
- 팔레트 hex 이탈 0건 · **팔레트 스케일 준수** — VGA 6bit 원값(0~63)을 그대로 저장하면 반려
  (8bit = 원값×4. 2026-08-24 1차 납품이 이 사유로 전량 교정됨: tools/dev/fix_6bit_png.py)
- 완전 투명 배경 · 앵커 하단 여백
- BGM/SFX는 본 브리프 범위 밖(오디오 파이프라인)

반려 리포트에는 수정 힌트가 붙는다(예: "프레임 3 배경 오염 → 네거티브 추가"). 해당 힌트를
프롬프트에 반영해 재생성. **에셋당 재시도 한도 N회 초과분은 사람 손보정으로 이관.**

## 6. 금지사항 & 커밋 규칙

| 금지 | 대신 |
|---|---|
| `res://assets/sprites/**` 직접 기록 | `assets/raw/<category>/<asset_id>/sheet_v{n}.png` 에만 저장 |
| `src/`, `data/`, `docs/`, `scenes/` 편집 | 건드리지 않음(버그 제보는 리포트) |
| style_bible.md / palette_master.json 직접 수정 | 변경 제안을 별도 md로 남기고 합의 |
| 커밋 메시지 자유 형식 | prefix `art:` + 자기 경로만 스테이징 |
